# 优惠券与订单说明

- 平台优惠券分两类：普通券（直接领取）和秒杀券（限时限量，每人限购一张）。
- 秒杀券下单后 30 分钟内未支付会自动取消，库存会释放回活动池。
- 订单状态：1=待支付，2=已支付，3=已核销，4=已取消。
- 已支付的订单需要退款，请联系商户或平台人工客服，当前版本不支持自助退款。
- 券的使用规则以券详情页为准，一般限制为「仅限堂食」「节假日不可用」「不与其他优惠同享」。

# 常见问题

Q：怎么查看我领了哪些券？
A：在「我的」-「我的券」里查看，可以调用 listMyVouchers 工具实时查询。

Q：秒杀没抢到怎么办？
A：秒杀券数量有限，抢完即止。未支付的订单取消后库存会释放，可以过几分钟再试。

Q：为什么下单提示「每人限购一单」？
A：秒杀券对同一用户限制一张，已经下过单的账号不能重复下单。

Q：附近有哪些店？
A：可以按分类查看附近商户，需要提供当前位置或选择商圈。
